| Available numeric medians | Approved treatment |
|---|---|
| All predecessors | Average all |
| Two predecessors | Average the two |
| One predecessor | Use that median |
| None | Leave missing |

- Preserve original non-numeric source markers.

- Do not introduce additional predictor-age or missingness features automatically.
