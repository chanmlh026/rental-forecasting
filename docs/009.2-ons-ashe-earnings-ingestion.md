### Components and execution

- `src/ingestion/ons_ashe.py`: production XLS/XLSX parsing, serial official ZIP
  acquisition, paired pay/CV validation, immutable raw reuse and validated output
  publication. Reuses existing source I/O, storage TOML, geography reference,
  checksums, safe HTTP metadata and atomic bundle publication.
- `configs/ons_ashe_editions.json`: pinned 37-edition contract derived from the
  reviewed investigation, with source labels/URLs and verified release evidence.
  Future editions require a reviewed inventory update, not silent discovery or
  substitution. No dependence on ignored investigation files for normal operation.
- `openpyxl==3.1.5` and `xlrd==2.0.2`: minimal runtime readers for the official
  XLSX/XLS formats and source styling. `uv.lock` also records their required
  `et-xmlfile` dependency. No new storage/framework/service is introduced.
- `tests/test_ons_ashe.py`: extraction, schema variations, legacy collisions,
  source conflict flags, markers/missingness, edition attribution, pay/CV alignment,
  malformed ZIPs, network restrictions/retries, incomplete responses, partial
  history prevention, immutable reruns/recovery and safe metadata tests.

```powershell
# Fresh environment: synchronise locked dependencies, then use official downloads.
uv sync --locked
uv run python -m ingestion.ons_ashe --snapshot-id YOUR-NEW-SNAPSHOT-ID

# Actual full-history run used verified original official response bundles:
uv run python -m ingestion.ons_ashe --snapshot-id 2026-11-21-task009-2 --source-cache data/raw/ashe-009-1-investigation

# Repeat the same snapshot without a supplied cache or network:
uv run python -m ingestion.ons_ashe --snapshot-id 2026-11-21-task009-2
uv run python reports/data_audits/009.2/validate_live.py
uv run pytest
```

`--config`, `--inventory` and `--geography-reference` select existing-style
configuration inputs. A completed output identity fingerprints inventory,
reference and transformation version. Use a new snapshot for changed inputs or
publisher bytes. Never delete/replace an existing source to force a rerun.
The optional cache importer verifies exact official URLs, successful status and
bundle checksums, and preserves original retrieval time; it does not relabel the
import date as original retrieval. It copies each original ZIP once into this
pipeline's owned immutable raw bundle, without separately duplicating extracted
workbooks. Existing investigation bundles remain unchanged and are optional.

Fresh network acquisition uses a transparent User-Agent, no credentials/cookies,
1.5-second serial pacing and at most three attempts. HTTP 429 and transient
server/transport errors have bounded retries. Numeric and HTTP-date Retry-After
are honoured; waits above 60 seconds stop for later resumption rather than
retrying early. HTTP 403 and other terminal responses stop. Safe allowlisting
applies to success and retained retry metadata. A fresh production retrieval of
the 2026 ZIP returned HTTP 200 with the reviewed SHA-256;
[retrieval evidence](../reports/data_audits/009.2/retrieval-evidence.json) records
the actual request. Real 429 evidence remains in Task 009.1; new retry tests use
controlled responses, not deliberate publisher throttling.

Checked [ONS terms](https://www.ons.gov.uk/help/terms-conditions),
[fair use](https://www.ons.gov.uk/help/fair-use-policy) and the
[dataset](https://www.ons.gov.uk/employmentandlabourmarket/peopleinwork/earningsandworkinghours/datasets/placeofresidencebylocalauthorityashetable8)
on 21 November 2026: aggregate content is published under OGL v3 with Crown/ONS
attribution; no selected-table exception observed. No restricted microdata,
access-control bypass or disabled certificate verification is involved.

### Outputs and provenance

All **37 editions, 2002–2026**, ingested successfully, retaining provisional,
revised, both 2006 methodology editions and both 2011 SOC editions. The source
definition is Table 8.7a, `All` D: annual gross median employee-job earnings,
both sexes and full-/part-time, GBP/year; paired 8.7b `All` D supplies CV percent.
Annual guide definition: tax year ending 5 April, adult-rate employee jobs held
for more than a year. Employee earnings are not household income. Owner rationale
and accepted limitation remain recorded in Task 009.1; usefulness is untested.

| Layer/path under `data/` | Files and interpretation |
|---|---|
| `raw/ons_ashe/snapshot=2026-11-21-task009-2/{edition_id}/` | Unmodified `response.bin` ZIP and manifest, one bundle per edition |
| `validated/ons_ashe/snapshot=2026-11-21-task009-2/` | Complete structurally validated source-derived tables and manifest |
| `processed/ons_ashe/snapshot=2026-11-21-task009-2/` | Same retained source observations, notes and coverage in standardised Parquet, without model selection or harmonisation |

Each derived bundle contains `observations.parquet` (**15,965 rows**),
`workbook_notes.parquet` (**1,731 rows**) and `coverage.parquet` (**37 rows**).
Total processed Parquet is about 415 KB. Full source tables include uncoded
national/regional aggregates as well as coded geographies and LAs; source row
counts must not be described as authority totals.

Observation key: `(source_edition_id, source_row)`. Rows preserve exact original
names/code strings, structurally normalised codes separately, pay/CV source rows,
numeric values, raw source text, marker/state fields and style/fill metadata.
`exact_cohort_match`, approved name and name-difference flags report direct-code
compatibility without translating geography. Both legacy code-68/69 rows survive.
No absent-cohort observations are manufactured. Coverage and manifests retain
missing cohort codes and unmatched source codes by observation year/edition;
names and row identities remain in observations.

Provenance includes edition label/status, reference period, verified release date
where available, explicit availability evidence, original retrieval timestamp,
URL, snapshot/ZIP checksum, selected workbook names/checksums, All sheet and
source rows. Notes preserve original Notes sheets and table footers, including
methodological warnings. Raw ZIPs retain all original workbooks/styles and other
source cells; unused earnings measures are not promoted to predictors.

- Publication dates are retained only for 2026 provisional and 2025 revised
  (22 October 2026). The other **35 editions** retain explicitly unverified
  historical availability. Edition release dates do not certify when each

- **Newly identified source-note conflict:** 2022 revised and 2023 provisional

  No footnote is silently corrected and no absence filter is applied. This source
