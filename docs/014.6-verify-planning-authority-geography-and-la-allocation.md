# 014.6 — Verify Planning Authority Geography and LA-Level Data Allocation

## Objective

Determine whether the existing MHCLG PS1/PS2 planning application data can be accurately mapped to the project's approved 294 Local Authorities, using the PIPR geographical reference.

Identify which planning authorities have directly compatible boundaries, which require aggregation, and which cannot be allocated reliably using existing data.

**This is a research-only task. Do not implement geographical harmonisation or modify ingested datasets.**

## 1. Review Existing Evidence

Review the latest repository state, relevant project documentation, Engineering Standards, AGENTS.md, Task 012 and Task 014.4 findings.

Use the existing ingested PS1/PS2 data and retained source evidence.

Preserve all previously approved methodology and decisions.

## 2. Verify LPA-to-LA Geographical Relationships

Investigate the official ONS Local Planning Authority to Local Authority District lookup, including the April 2025 edition.

For the approved 294 Local Authorities, determine:

- Which have one directly compatible, coterminous LPA.
- Which contain multiple LPAs operating within the same LA.
- Which share planning authority responsibilities with other LAs.
- Which have unresolved or historically changing boundaries.

Use official boundary, lookup and planning authority documentation to verify these classifications.

A matching LA/LPA code alone must not be treated as proof of identical geographical coverage.

Respect ISS-022: do not undertake new automated ONS acquisitions until the required authorisation is resolved. Use existing files and accessible official documentation where permitted.

## 3. Assess Existing Planning Data

Inspect all relevant authority records already retained in the full PS1 and PS2 histories, including:

- District council LPAs.
- National Park Authorities.
- Development corporations.
- Historical predecessor planning authorities.
- Records with legacy, missing or non-standard geographical identifiers.

Determine whether usable planning application and decision counts exist for each relevant authority and reporting quarter.

Distinguish missing values from missing LA-code matches.

Do not treat application counts as dwelling-unit permissions.

## 4. Assess Historical Coverage

Cover **2015 Q1 to 2026 Q2**, including the 11 reorganised Local Authorities.

For every LA and quarter, classify the availability of the relevant planning measures:

| Classification | Meaning |
|---|---|
| Direct | One verified coterminous LPA with usable observations |
| Additive | Complete, non-overlapping LPA or predecessor counts can be summed |
| Allocation required | An LPA spans multiple LAs and its total cannot be assigned directly |
| Missing | Required observations are unavailable in the investigated sources |
| Unverified | Insufficient geographical or source evidence |

Pay particular attention to the 271 historical LA-quarter records without modern LA-code matches identified in Task 012.

Use historically appropriate LPA boundaries and responsibilities wherever evidence is available. Do not assume the April 2025 lookup applies unchanged to every historical quarter.

## 5. Quantify the Results

Produce a clear summary containing:

1. Number of the 294 LAs that are directly coterminous, split, shared or unresolved under the latest verified geography.
2. Names and codes of every non-coterminous LA and its associated LPAs.
3. Number of LA-quarter observations in each classification.
4. Number of historical observations potentially recoverable through verified addition.
5. Number requiring allocation or further information.
6. Any limitations affecting PS1 and PS2 differently.

Provide detailed LA × quarter evidence and reproducible source references.

Do not describe observations as complete merely because matching codes or numerical records exist.

## 6. Identify Practical Resolution Options

For each unresolved case, recommend the simplest defensible approach:

- Direct use of existing planning counts.
- Summation of complete, geographically compatible counts.
- Further geographical or application-level evidence.
- A clearly identified approximation for later owner consideration.
- Leaving observations missing where reliable allocation is not possible.

Do not select or implement an approximation without project-owner approval.

Prioritise existing official sources over new ingestion.

## 7. Constraints

- Research and validation only.
- No changes to production ingestion, raw data, validated datasets or modelling outputs.
- No imputation, allocation or reconstructed planning counts.
- No unauthorised ONS downloads or access workarounds.
- Preserve original source codes, names, reporting periods and provenance.
- Distinguish confirmed findings from assumptions.
- Preserve ISS-003, ISS-004, ISS-010, ISS-017 and ISS-022 as Open unless separately authorised.
- Do not change the approved PIPR reference geography or planning variable definitions.
- Follow existing project documentation and task-logging conventions.

## 8. Acceptance Criteria

The task is complete when:

1. The 294-LA geographical relationship assessment is reproducible.
2. All relevant existing PS1/PS2 planning authority types have been assessed.
3. The 2015 Q1–2026 Q2 coverage classifications are documented.
4. The 271 historical code-mismatch cases have been investigated.
5. Directly usable, additive, allocation-required, missing and unverified observations are quantified separately.
6. Outstanding geographical limitations and source gaps are clearly identified.
7. Independent validation checks reconcile the assessment with retained source records.
8. All original ingested data remain unchanged.

## 9. Documentation and Delivery

Record findings in the existing Data Dictionary, Issue Register and Phase 2 Development Journal as appropriate.

Archive this task prompt and its execution timing according to the existing project conventions.

Create a dedicated research branch and pull request for independent review. Do not merge automatically.

## Final Report

Summarise:

- Total LAs with directly compatible planning geography.
- Total LAs with split or shared LPA responsibilities.
- Total LA-quarter records recoverable from existing data.
- Total unresolved LA-quarter records.
- Evidence sources and validation outcomes.
- Any methodology decisions requiring project-owner approval.
- Branch, commit SHA, PR link and measured execution time.
