# 007.1. Investigate Bank of England IUMZID4 Historical Revisions and Publication Vintages

## Objective

Investigate whether the Bank of England provides access to originally published values, subsequent revisions and historical publication dates for the IUMZID4 buy-to-let (BTL) mortgage-rate series.

The purpose is to determine how historical data vintages should be handled in the forthcoming Bank of England ingestion pipeline (Task 007), particularly for point-in-time forecasting and backtesting.

This is a **source investigation and evidence-validation task only**.

Do not implement production ingestion code or make unapproved methodological decisions.

## 1. Project Context

The UK Rental Forecasting Project aims to predict average monthly private rents for English Local Authorities, 12 months ahead.

The selected financing variables currently include:

- Bank of England Bank Rate.
- Bank of England IUMZID4 — two-year fixed BTL mortgage rate at 75% LTV.

Two existing issues are relevant.

### ISS-004 — Historical publication availability and revisions

Historical values downloaded today may differ from the values originally available at past forecast dates.

The Bank of England's Interactive Statistical Database documents functionality for viewing revised observations and previous values.

However, this functionality has not yet been independently verified for IUMZID4.

### ISS-005 — Financing-rate methodology and publication history

IUMZID4 underwent documented methodological changes beginning with February 2019 observations.

The Bank's published assessment estimates an overall methodology impact of approximately −0.17 percentage points for this BTL category, based on illustrative August–September 2018 comparisons.

The project owner has decided:

- Retain IUMZID4 as the selected BTL financing indicator for now.
- Preserve original published observations without statistical correction.
- Document the 2019 methodological transition.
- Defer decisions about modelling treatment of the transition.
- Investigate the availability of historical revisions before finalising the ingestion design.

Do not interpret these decisions as approval to construct new features or adjust historical observations.

### Documented capability versus demonstrated behavior

The [IADB Help](https://www.bankofengland.co.uk/boeapps/database/Help.asp)
describes new/revised-data filtering from a 3 June 2007 baseline, previous-value
links in HTML/Excel, and publication history in XML rather than CSV. Its XML
parameters include VUD=A (all observations) or B (updated observations), with
VUDdate selecting changes since a date. These describe update selection, not
an as-of cutoff. Help names LAST_REVISED; the actual responses use LAST_UPDATED.
Preserve observed schema attributes instead of assuming those names match.

| Method | IUMZID4 result in this investigation |
|---|---|
| CSV | Current 178 monthly rows, Jan 2012-Oct 2026; no publication/revision history in the returned data. The selected Jan-Mar 2019 values match XML. |
| XML without VUD | Current values and LAST_UPDATED, but no Revision children for Jan-Mar 2019, despite revisions being present in the history-enabled response. |
| XML with VUD=A, VUDdate=03/Jun/2007, VPD=Y, VFD=Y | Retained history returned for selected revised months, including PROV_VALUE and OBS_VALUE events with UPDATE_TIMESTAMP. |
| XML VUD=A, VUDdate=01/Apr/2019 | Jan-Mar 2019 current values remain current; earlier revision events disappear. It does not return values as of 1 April. |
| XML VUD=B, VUDdate=01/Jun/2019 | Returns only February 2019 from the selected three months, with the 7 June revision. |
| HTML / Excel export | Jan-Mar 2019 numeric values match CSV/XML. Excel download is HTML with application/vnd.ms-excel, not an XLSX ZIP. These tested exports did not expose previous-value links, including when XML-style VUD parameters were supplied. |
| HTML revision controls | Explicit Filter=Y attempts were unsuccessful: selection returned an HTTP 200 application error about too many series; data pages redirected to ErrorPage.asp, also HTTP 200. These attempts do not establish that the documented UI facility is unavailable. XML history is the demonstrated route. |

Bootstrap command-line access first hit sandbox WinError 10061, then a source
HTTP 403 outside the sandbox. Replaying with a browser user agent returned HTTP
200; the follow-up reproduced 403 with Python-urllib/3.12. This is observed
request-dependent access behavior, not proof of the underlying server's reason
or guaranteed future access. Web browsing also failed on the dynamic export
URLs while command-line probes succeeded. Two guessed release-page routes for
February/January 2019 were inaccessible; they are not evidence of absent releases.
The first temporary-body read required filesystem permission; an output encoding
failure was corrected without changing the responses. These local tool failures
are distinct from source-data absence.

### Publication schedule and first availability

The [current quoted-rates notes](https://www.bankofengland.co.uk/statistics/details/further-details-about-quoted-household-interest-rates-data)
specify monthly publication on the fifth working day of the following month,
with subsequent reweighting and possible later corrections. Mortgage weights
can be updated when concurrent quarterly information becomes available. This is
not a two-year hard revision limit. The [March 2019 article](https://www.bankofengland.co.uk/statistics/articles/2019/introduction-of-new-quoted-rates-data)
announced the move to monthly publication; its PDF footnote explains the previous
21st-working-day update and replacement by next-month reweighting.

Retained 2019 release/update records include 7 February, 7 March, 5 April,
8 May and 7 June at 09:30:00; recent records include 7 October and 6 November
2026. These corroborate selected post-change publication dates programmatically.
The February 2019 earliest retained event agrees with the dated 7 March 2019
announcement. They are database update records, not independently audited
public release timestamps for every month. Do not extrapolate a complete
historical calendar or assign these dates to all observations in an export.

The [general FAQ](https://www.bankofengland.co.uk/statistics/faqs) still states
a fifth-and-21st-working-day quoted-rate cadence. The dated 2019 change explains
a historical regime distinction; the FAQ must not override the specific later
methodology. The 2016/2018 sample histories do not certify every pre-change
initial release or update date. The [September 2016 announcement](https://www.bankofengland.co.uk/-/media/boe/files/statistics/bankstats-articles/2016/forthcoming-improvements-to-interest-rate-statistics---bankstats-article.pdf)
identifies IUMZID4 in Annex 3, backdated to January 2012 and to be published with
Bankstats on 31 October 2016. January 2012's LAST_UPDATED matches that date,
but its exact time is a database update time, not independently verified public
availability. The whole 2012-2016 backfill was not available at its observation
dates. Missing earlier provisional events must remain a disclosed evidence gap.

### February 2019 methodology context

The source notes apply the changed basis from February 2019: wider lender
coverage and monthly averages replace the earlier ER-sample/end-month basis.
Their product-specific table retains quarterly MLAR weights for **BTL before
and after February 2019**. The broader article's PSD description must not be
misread as a demonstrated BTL switch to PSD. Later weights can revise rates;
source vintages and measurement regimes are separate metadata dimensions.

The [November 2018 design article](https://www.bankofengland.co.uk/statistics/articles/2018/forthcoming-changes-to-quoted-interest-rates-data-2019)
describes the expanded market sample and changes to product selection, including
selection using fees and the representative mortgage size. The 2019 PDF qualifies
the size change as owner-occupier-specific and includes cashback consideration.
Do not assume every selection change has a nonzero BTL effect. The current source
still publishes headline advertised rates, not fee-inclusive APR estimates.
IUMZID4's own data also carries a July 2018 population-expansion note in the HTML
output; preserve that earlier break information during source onboarding.

The [2019 PDF, Annex 1](https://www.bankofengland.co.uk/-/media/boe/files/statistics/bankstats-articles/2019/introduction-of-new-quoted-rates-data.pdf)
reports a **-0.17 percentage-point** overall BTL two-year 75% LTV impact, averaging
illustrative August-September 2018 comparisons. Its charts label new-basis values
before February 2019 illustrative. This verifies a limited parallel-calculation
comparison, not a downloadable, complete BTL history under both methods. No
machine-readable parallel BTL panel or complete counterfactual vintage series
was demonstrated. The figure is not an adjustment factor for other months.
